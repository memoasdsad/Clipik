📄 POLÍTICA DE PRIVACIDADE – Meu Bolso

Última atualização: 12/12/2025

Esta Política de Privacidade descreve como o aplicativo Meu Bolso, desenvolvido por Victor Marques Ghion, coleta, usa, armazena e protege as informações dos usuários. Ao utilizar o aplicativo, você concorda com os termos descritos a seguir.

📌 1. Informações que Coletamos
1.1. Informações fornecidas pelo usuário

O Meu Bolso pode armazenar dados inseridos diretamente pelo usuário, como:

Gastos

Receitas

Categorias

Metas financeiras

Anotações e descrições relacionadas às suas finanças

Essas informações são salvas localmente no dispositivo, a menos que o usuário utilize funcionalidades externas de backup (quando disponíveis).

1.2. Informações coletadas automaticamente

Para funcionamento e melhoria do app, podemos coletar automaticamente:

Informações do dispositivo

Versão do sistema operacional

Idioma

Dados de uso (como telas acessadas)

Identificadores anônimos para exibição de anúncios (Google AdMob)

Esses dados não identificam o usuário individualmente.

📌 2. Como Usamos as Informações

Usamos os dados coletados para:

Registrar despesas, receitas e metas financeiras

Organizar e gerar relatórios

Exibir anúncios (Google AdMob)

Aprimorar a experiência do usuário

Melhorar estabilidade, desempenho e funcionalidades do app

Nenhum dado financeiro é compartilhado de forma identificável.

📌 3. Compartilhamento de Informações

O app não compartilha informações pessoais do usuário com terceiros.

Podemos compartilhar dados não identificáveis com:

Google AdMob (para exibição de anúncios)

Serviços de análise anônima (caso implementados no futuro)

O Meu Bolso não vende informações pessoais do usuário.

📌 4. Armazenamento e Segurança

Todos os dados financeiros inseridos no app são armazenados localmente no dispositivo.

Não enviamos informações financeiras para servidores externos.

Utilizamos medidas de segurança para proteger os dados, mas nenhum método digital garante segurança absoluta.

A responsabilidade pela segurança física do dispositivo é do usuário.

📌 5. Permissões Utilizadas

O app pode solicitar:

Acesso à Internet: necessário para exibir anúncios e atualizações.

Armazenamento: para salvar dados localmente no dispositivo.

O app não solicita acesso a contatos, localização, câmera, microfone ou qualquer permissão sensível sem aviso prévio.

📌 6. Anúncios

O Meu Bolso utiliza Google AdMob para exibir anúncios dentro do aplicativo.
O Google pode coletar informações como:

Identificador de publicidade

Dados de interação com anúncios

Informações sobre o dispositivo

Para saber mais, consulte:
👉 Política de Privacidade do Google: https://policies.google.com/technologies/ads

📌 7. Direitos do Usuário

O usuário pode:

Excluir seus dados diretamente no app

Solicitar informações através do nosso email de suporte

Desinstalar o aplicativo para interromper qualquer coleta futura de dados

📌 8. Crianças

O aplicativo não é destinado a menores de 13 anos.
Não coletamos intencionalmente dados de crianças.

📌 9. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente.
A versão mais recente sempre estará disponível dentro do app ou na página informada na Play Store.
